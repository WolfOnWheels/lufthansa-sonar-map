# Lufthansa Sonar Map

Live map of airborne Lufthansa (LH) flights (data: [AirLabs API](https://airlabs.co)), set to three synchronized audio tracks.

- `index.html`: flat map with octilinear coastlines. Flights glow by altitude layer (Ground 0–450 m yellow, Between 450–10,000 m lime, Air above 10,000 m cyan). Each note of the Between track flashes the ring of one random Between flight and shows its flight number and route.
- `mockup.html`: the map shown on a digital display in an airport lounge.

Press Play to start the audio; each track has its own volume control.
